# Windows 10 Smooth PC Setup

This checklist helps prepare a Windows 10 PC for smoother Roblox Studio and Roblox Player performance.
It focuses on safe operating-system, driver, graphics, network, and in-game settings.
It does not include registry hacks, exploit tools, FPS unlockers, anti-cheat bypasses, or downloads from unknown sources.

## Before You Change Settings

1. Create a Windows restore point so you can undo system changes if something feels worse.
2. Write down your current Roblox graphics level, monitor refresh rate, and average FPS in the places you normally play or test.
3. Install updates only from Windows Update, your PC manufacturer, or the official NVIDIA, AMD, or Intel driver sites.
4. Restart the PC after major Windows, driver, or Roblox updates before judging performance.

## Windows 10 Settings

1. Open **Settings > Update & Security > Windows Update** and install important updates.
2. Open **Settings > System > Power & sleep > Additional power settings** and choose **High performance** when plugged in.
3. Open **Settings > Gaming > Game Mode** and turn **Game Mode** on.
4. Open **Settings > Gaming > Captures** and turn off background recording if you do not use it.
5. Open **Settings > Apps > Startup** and disable apps you do not need while playing or testing.
6. Keep at least 15% to 20% free space on the drive where Windows and Roblox are installed.
7. Run **Windows Security > Virus & threat protection** scans regularly, especially if the PC suddenly becomes slow.

## Graphics and Display

1. Set the monitor to its highest supported refresh rate in **Settings > System > Display > Advanced display settings**.
2. Set Roblox or Roblox Studio to use the dedicated GPU in **Settings > System > Display > Graphics settings** if the PC has both integrated and dedicated graphics.
3. Update GPU drivers from the official GPU vendor or PC manufacturer.
4. Close heavy overlays, screen recorders, browsers, and launchers while testing FPS.
5. If the PC is a laptop, plug in the charger and make sure the laptop is not in battery saver mode.

## Roblox Settings

1. In Roblox, open **Settings**, set **Graphics Mode** to **Manual**, and lower **Graphics Quality** until frame pacing is smooth.
2. Prefer fullscreen or a lower window resolution on weaker PCs.
3. Test in several experiences because FPS depends on each experience's scripts, assets, lighting, networking, and player count.
4. Avoid using unofficial FPS unlockers or modified clients; they can break, create security risks, or violate platform rules.

## Network and Lag Checks

1. Use Ethernet when possible; otherwise, use a strong 5 GHz Wi-Fi signal close to the router.
2. Pause large downloads, cloud sync, and streaming on the same PC or network while playing.
3. Restart the router if ping spikes affect every game or device.
4. Choose Roblox servers or experiences that are closer to your region when the experience offers that choice.

## Quick Test Plan

1. Restart the PC.
2. Close unnecessary startup apps and overlays.
3. Open Roblox or Roblox Studio and test the same place for five minutes.
4. Record average FPS, big stutters, ping, graphics level, and whether the laptop was plugged in.
5. Change one setting at a time, then repeat the same five-minute test so you know what helped.

## Safe Troubleshooting Order

If the PC still lags, try fixes in this order:

1. Lower Roblox graphics quality.
2. Close background apps and overlays.
3. Update Windows and GPU drivers from official sources.
4. Check storage space and malware scans.
5. Test Ethernet or a stronger Wi-Fi connection.
6. Reduce heavy assets, particles, shadows, and scripts if the lag happens in your own Roblox experience.
7. Upgrade hardware only after you have measured whether the bottleneck is CPU, GPU, RAM, storage, or network.
